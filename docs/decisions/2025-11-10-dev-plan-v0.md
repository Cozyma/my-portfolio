# 2025-11-10: 開発手順 v0（レイヤード構成で最小実装）

目的: 小さく出して早くつなぐ方針のもと、バックエンドは厳密なレイヤード（Controller → Service → Repository）で実装し、フロントは最小の表示と API 連携から開始する。

## バックエンド（Laravel/Bref）
- エンドポイント v0
  - `GET /api/health` ヘルスチェック（200 OK）
  - `GET /api/profile` プロフィール（静的データ）
  - `GET /api/works` 制作物一覧（静的データ）
- レイヤード構成
  - Controller: 入出力の制御のみ
  - Service: ユースケース/集約ロジック
  - Repository: データ取得（v0 は InMemory 実装で静的データ）
- 応答形式
  - Laravel Resource で `{ data, meta? }` を返却
- 以降拡張
  - `/api/contact` は次フェーズ。レート制限/CORS/ログ強化も段階導入

## フロント（React + Vite + Tailwind/DaisyUI）
- v0 範囲
  - API クライアント（`VITE_API_BASE_URL` で切替）
  - Home/Works の最小表示
- 以降拡張
  - Contact フォーム、UI 拡張（必要時のみ shadcn/ui）

## 運用
- 重要な変更は `docs/decisions/` に追記
- デプロイは GitHub Actions（OIDC）。設定は `docs/deploy-setup.md` を参照
