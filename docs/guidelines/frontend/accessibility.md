# アクセシビリティ（a11y）

基本原則
- セマンティクス: 正しい HTML 要素を使用（見出し、リスト、ボタン/リンクの区別）。
- フォーカス: キーボード操作可能、フォーカスリングを隠さない（Tailwind の `focus-visible` を活用）。
- 対比: WCAG のコントラスト比を満たすテーマを選択（DaisyUI テーマの確認）。
- ARIA: 必要最小限で付与。ARIA での置き換えよりもネイティブ要素の活用を優先。

実装ヒント
- ダイアログ/ポップオーバー等は shadcn/ui（Radix）を採用してフォーカストラップ/ARIA を既定で担保。
- 画像には適切な `alt`。装飾目的の画像は空 `alt`。
- フォームには `label` とエラーの関連付け（`aria-describedby`）。

チェック
- 手動: キーボードのみで主要フローを操作可能かを確認。
- 自動: `axe`/`@axe-core/react` の導入は後日検討（v0 は手動で十分）。
